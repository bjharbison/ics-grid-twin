Notes on Live Mode

In live mode every value is the firmware's own — no generation. Load factor is never published, so the readout is estimated from current for coherence only. The parser is topic-depth agnostic (grid/<tag> or grid/<board>/<tag>) and folds any legacy _phase_ names back to canonical — resolve the exact shape against your owed mosquitto_sub -t 'grid/#' capture. Historical replay from InfluxDB ics-telemetry is the next source to add behind this same toggle.
